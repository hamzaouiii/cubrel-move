# Das Dashboard in Cubrel verstehen

In diesem Artikel geht es darum, was das Dashboard anzeigt, welche Widget-Arten Sie hinzufügen können, und wie Anordnung, Filterung und Aktualisierung funktionieren.

## Ihr eigenes Dashboard

Jeder Benutzer hat sein eigenes **Dashboard**, es gibt kein separates, gemeinsames oder Team-Dashboard. Änderungen an Ihrer Anordnung wirken sich nur auf das aus, was Sie selbst sehen. Neue Benutzer starten mit einer sinnvollen Standardanordnung, die von ihrer Rolle abhängt (die Startanordnung eines Administrators unterscheidet sich von der eines Benutzers mit nur Lesezugriff), von dort aus gehört sie aber Ihnen, um sie umzugestalten.

## Widget-Arten

Klicken Sie auf **Widget hinzufügen**, um zu sehen, was verfügbar ist:

- **Kennzahl**: eine einzelne Zahl für ein Modul, eine Anzahl, Summe oder ein Durchschnitt eines Feldes.
- **Datensätze im Zeitverlauf**: ein Linien- oder Balkendiagramm der Werte eines Feldes über die Zeit.
- **Aufschlüsselung**: ein Donut- oder Balkendiagramm, das Datensätze nach einem Feld gruppiert (z. B. Verkaufschancen nach Phase).
- **Datensatzliste**: eine kompakte Tabelle mit Datensätzen aus einem Modul.
- **Personen**: eine Rangliste, die Personen nach einem summierten, gezählten oder gemittelten Feld einordnet.
- **Meine Datensätze**: ein einfaches Widget, das Ihnen zugewiesene Datensätze über alle Module hinweg zeigt.

Die ersten fünf sind **konfigurierbar**: Sie wählen das Modul und optional Filter (zum Beispiel "nur offene Verkaufschancen"). **Meine Datensätze** ist nicht konfigurierbar, es ist ein festes Widget, das Sie hinzufügen oder entfernen, aber nicht anpassen können.

Standardmäßig zeigt ein Widget nur Datensätze, die Ihnen gehören. Als Administrator lassen sich manche Widgets stattdessen so einstellen, dass sie jeden Datensatz im Modul zeigen, nicht nur Ihre eigenen.

## Ihre Anordnung bearbeiten

Klicken Sie auf das Stiftsymbol, um in den Bearbeitungsmodus zu wechseln. Von dort aus können Sie:

- **Widgets per Ziehen neu anordnen**.
- Die Konfiguration eines Widgets **bearbeiten** (Modul, Filter, Diagrammtyp, wo zutreffend).
- Ein Widget **entfernen**.
- Beim Hinzufügen eine **Breite** für ein Widget wählen (sie bleibt danach fest, es gibt kein freies Anpassen der Größe später, nur ein Neuanordnen).

Widgets fließen automatisch in ein Raster, ähnlich einem Mauerwerk-Layout, es gibt keine manuelle Platzierung in Zeilen oder Spalten. Speichern Sie Ihre Änderungen, wenn Sie fertig sind, oder brechen Sie ab, um sie zu verwerfen.

## Daten aktualisieren

Nichts auf dem Dashboard aktualisiert sich im Hintergrund von selbst. Klicken Sie auf **Alle aktualisieren**, um die Daten jedes Widgets bei Bedarf neu abzurufen.

## Kurz gefasst

| Frage | Antwort |
| --- | --- |
| Gibt es ein Dashboard pro Benutzer oder ein gemeinsames? | Eines pro Benutzer, rein persönlich |
| Welche Widget-Arten gibt es? | Kennzahl, Datensätze im Zeitverlauf, Aufschlüsselung, Datensatzliste, Personen, sowie das feste Widget Meine Datensätze |
| Lässt sich ein Widget auf ein Modul beschränken und filtern? | Ja, bei jeder Art außer Meine Datensätze |
| Zeigt ein Widget alle Datensätze oder nur meine? | Standardmäßig nur Ihre eigenen; manche Widgets lassen sich für Administratoren auf "alle" umstellen |
| Kann ich Widgets neu anordnen? | Ja, per Ziehen im Bearbeitungsmodus |
| Kann ich ein Widget nachträglich in der Größe ändern? | Nein, die Breite wird beim Hinzufügen festgelegt |
| Aktualisiert sich das Dashboard automatisch? | Nein, nutzen Sie **Alle aktualisieren** |
